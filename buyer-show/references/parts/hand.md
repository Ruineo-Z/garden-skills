# 手部 · 腕部配饰 · 部位参考

覆盖：手链、手表、戒指、手镯、美甲、袖扣。以下为部位特有参考，拍法按主说明从日常拍摄情境共同推导，不是固定套餐。

## 穿戴判断

- **锚点**：手指、指节、手腕、腕骨、袖口。
- **机制**：闭环、搭扣、弹性、袖扣固定结构。
- 戒指 / 手镯内径须适配相应身体部位，手链 / 手表须能绕腕；不要为适配改变商品尺寸或扣具。
- 手表表盘朝向、戒指位置或叠戴方式应符合本次佩戴关系；不为装饰额外复制目标商品。

## 拍摄与取景

- 手腕与手可自然置于视线下方，本人从上方或斜上方拍摄时能看屏幕并调整佩戴手的位置，因此俯拍局部是常用拍法。另一手持机，支撑与取景配合本次手部姿态，不固定放在桌面或腿上。
- 自拍局部：佩戴手与持机手必须分开，机位朝向佩戴手，不机械套用面部自拍。
- 帮拍：按普通手机可对焦的距离拍手与手腕，不固定一到两米；不默认设计成珠宝微距特写或强烈背景虚化。
- 取景记录日常佩戴关系，通常包含手、手腕、部分前臂与相邻环境，而非将手链放大到占据画面主体。商品可辨认即可，不为逐个展示饰件收紧取景；半身时也不能让目标小到失去佩戴信息。
- 局部图同样执行 `../realism-library.md` 的普通手机成像要求：细小饰件不必全部同样锐利，皮肤、金属与织物的明暗和清晰度随现场光与焦点变化，不用逐处提亮、强调闪耀或均匀柔光表现商品。

## 展示关注点

与手指 / 手腕的比例、松紧与扣具位置、颜色和肤色的关系。表盘、戒面等细节需要合适取景，不意味着输出已经审核。

## 用户反馈后的诊断

- 手指数量、关节或指甲结构异常，手指粘连、手腕比例失真。
- 戒指陷入皮肤或悬浮，手链断裂、穿模或不贴腕。
- 表带与手腕脱离，表盘朝向错误、指针 / 刻度被改写。
- 袖扣离开袖口，指甲油涂到皮肤。

手部容易出现结构问题，但此清单只用于用户反馈后的定位，不要求出图后逐条检查。
