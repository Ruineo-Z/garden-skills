# 真实买家秀质感

普通人在日常生活中用手机记录佩戴 / 使用效果，可以为了看清佩戴效果移动位置、打开日常用灯、短暂停下来调整姿势；衣着与妆发来自当天的生活状态，不默认专门为这张买家秀做完整准备。场景好看与场景精致是两回事：环境可以有自然的美感，装修、设施和陈设仍采用普通日常水平，不围绕完整的装饰风格设计空间。不要求把照片拍糊、拍暗或弄乱背景。

拍法、取景、姿势和多张差异化统一按 `../SKILL.md` 推导；本文件指导画面质感与环境使用状态，不另选拍法或姿势。

## 普通手机成像

**每份最终 prompt 都须表达轻微但可见的白平衡偏差与细微噪点，包括光线充足的场景。**白平衡随现场光略偏暖或偏冷，画面不完全校正为中性色；噪点细而可见，在平滑区域与暗部保留普通手机颗粒，不只写成几乎看不到的暗部噪点。强度以正常观看能感到轻微成像不完美为准，商品颜色仍可辨认、细节不被遮蔽，不做明显色偏或粗颗粒滤镜。其余成像表现按现场条件取舍，不把过曝、模糊或广角畸变一起设为必需。

- **光线与白平衡**：先判断该地点在当前日常活动中通常如何照明，再沿用这个条件拍照。室内默认采用能正常活动、看清人物和商品的普通室内照明，室外沿用当时的日光条件；照明不足时可以开日常用灯或移动到较亮的位置。最终文本写清实际光源与整体照明即可，不额外设计光源之间的方向、色温对比或人物轮廓光来营造氛围，也不因晚间场景就主动关暗房间。日常照明本身可以有明暗和颜色差异，按实际条件保留，不把它们加工成突出人物或商品的布光方案。上述轻微白平衡偏差来自手机自动白平衡，单一普通光源下也可以出现，不为满足偏色要求新增另一种光源。用户明确指定特殊照明情境时沿用其要求。
- **手机成像与修饰**：商品和佩戴关系清楚可辨即可，纹理与细小部件的清晰度服从拍摄距离和焦点；不要求皮肤、织物、金属和背景同时纤毫毕现，不使用过度锐化、磨皮或逐处提亮来追求商业精修效果。保留自然纹理与克制的细微噪点，按正常手机近拍的对焦范围呈现，不默认添加突出商品的强烈背景虚化或微距效果。低光下可进一步有暗部细节损失或有限动态范围，成像效果不得掩盖本张要记录的商品信息。
- **构图**：取景像普通人记录效果，允许轻微偏移或局部裁切，但保留目标商品及必要穿戴关系。不为制造随手感主动倾斜画面。
- **环境**：先按主说明选择装修、设施和陈设普通的日常环境，再确定这个地点平时如何被使用，以及拍照时周围正在发生什么。好看可以来自现场本来的颜色、空间和日光，不需要用考究装修、成套装饰或精心配色来实现；增加杂物和使用痕迹也不能把过于精致的空间变成普通环境。根据实际活动，具体描述现场物品如何摆放、使用在表面留下了什么痕迹、周围的人正在做什么，并按取景保留可见内容。描述要落到实际对象、位置和状态，不能用“有生活气息”“保留使用痕迹”代替。物品的选择与摆放来自实际用途，不主动围绕商品和衣着统一配色、协调材质或安排陈设。环境可以整洁，但不应因为拍摄人物就被清空或统一处理得光洁如新。具体内容与数量由场景及取景决定，不要求每张同时出现上述所有内容，不从固定清单里抽取物品、污渍或人物来装饰背景。
- **人物**：可见面部时明确选用素颜或简单日常淡妆，不能仅省略妆容描述后任由模型补出完整妆面。简单淡妆只作少量日常修饰，仍看得到皮肤本来的纹理与轻微肤色不均，不形成精确完整的眼妆、立体修容和光洁无瑕的底妆。皮肤可有少量自然瑕疵，程度与位置随人物变化，不每张复制同一处斑点、痘印或泛红，也不靠大量瑕疵使人物显得刻意邋遢。发型、表情和视线来自当天生活状态，不统一要求微笑、看镜头或精致仪态；用户明确指定人物妆发时优先遵从。

人物的日常妆发、皮肤状态与环境使用状态随人物与情境写入最终 prompt；另用一段短文字表达本次现场光、轻微但可见的白平衡偏差与细微噪点，以及与拍摄距离相符的清晰度。不能仅以“干净清晰、保留纹理、不精修”代替这些具体要求，也不逐项添加所有效果。画质调整用于还原普通手机拍摄，不承诺靠噪点或偏色解决人脸本身的生成问题。

## 背景文字

不要求无关招牌清晰可读，也不把具体店名作为场景成立的条件；可以保留正常的街边或店内环境，不全面禁止背景文字。文字准确性受模型能力限制，不向每份 prompt 追加“招牌文字必须正确”。

用户反馈后，远处模糊小字不影响真实感时可以接受；醒目的乱码明显破坏画面时，再按要求调整取景、裁切或局部修复。商品本身的文字 / logo 属于商品保真问题，按主说明和对应部位处理。本节不增加自动看图审核或重试。
