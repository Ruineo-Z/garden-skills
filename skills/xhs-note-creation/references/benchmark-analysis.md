# 对标分析

## 职责与时机

在选题、封面、文案任一环节需要参考别人怎么做时使用。分两件事：**找**对标，和**拆**对标。

- 用户已经指定对标（链接、截图、账号名）→ 直接进入拆解。
- 用户没指定但想找参考 → 先找，列出候选请用户确认后再拆。

对标只用来理解做法。读者的需求可以相同，但这一篇的商品事实、经历和画面必须是自己的。

## 找对标

按下面三条一起缩小范围，不要只看品类：

1. **人群**：和你这一篇写给的是同一批人（年龄、地域、身材困扰、生活状态）。
2. **场景与需求**：解决的是同一类问题，不一定是同一个商品。
3. **体量可比**：优先看粉丝量级和你接近的账号。头部账号的做法常依赖已有的粉丝基础，直接搬到自己账号上不一定成立。

搜索时用人话组合，别只搜品类词：`人群 + 场景 + 需求`（如"小个子 通勤 披肩"）比单搜"披肩"更容易找到对口内容。

找到之后先筛一道：**看评论区在讨论什么**。讨论的是读者自己的处境，说明方向对；讨论的是别的东西，说明只是话题被蹭到了，不适合当方向参考。

给用户列候选时，每条说清为什么值得看（人群像、需求对、做法可借鉴），并请用户确认，不直接进入执行。

## 拆对标

拆的时候把**画面**和**文字**分开，两者用途不同。

### 画面层

画面部分的拆解方式写在 [封面创作](cover-creation.md#2-理解对标图) 里：看它靠什么吸引视线、光线和构图怎么组织人物与环境。拆的是做法，不是照搬人物、服装、道具和贴纸。

### 文字层

按下面几项逐条填，能填满的才算拆过：

| 项目 | 看什么 |
|---|---|
| 标题 | 先说读者关心的什么，商品词放在哪，一共几个信息点 |
| 正文开头 | 第一句接住了读者的什么问题 |
| 正文主体 | 讲了几件事，先讲什么后讲什么，卖点是怎么说出来的 |
| 结尾 | 落在哪里，有没有留下讨论空间 |
| 话题标签 | 覆盖了哪几类词，彼此之间是什么关系 |
| 评论区 | 置顶或高赞评论在补充什么信息 |
| 发布时间 | 和季节、节点有没有关系 |

填完之后再问一句：**这篇靠什么成立**。是画面、是信息量，还是读者处境写得太准。找到那件东西，再判断它能不能用在这一篇上。

## 借鉴的边界

- **不继承事实**：对标的材质、尺寸、价格、销量、顾客反馈都不是你的商品事实，一句都不能直接搬过来。
- **不继承经历**：对标的个人故事、使用场景、情绪经历属于原作者，不挪用。
- **不搬原文**：标题和正文用自己的话写。摘出结构和角度就够，句式和用词要重写。
- **不搬画面**：不复制原图的人物、服装、商品、文字贴纸和界面元素，只借鉴可复用的拍摄和排版思路。
- **只借适用的部分**：画面好看的对标不自动成为文字参考，文字写得好也不自动成为画面参考。

## 能看到的数据

如果能看到对标的互动数据，把它当作**方向是否被接受**的信号，而不是要追赶的目标：

- 互动量明显高于同类内容 → 这个方向读者买账，值得考虑。
- 互动量很低 → 可能没人搜，也可能方向没吸引力，先别当参考。
- 收藏明显高于评论 → 有用但不引发讨论，属于工具型内容。
- 评论明显高于收藏 → 引发共鸣或讨论，属于情绪型内容。

指标的具体参考区间和诊断方法见 [数据诊断](data-diagnosis.md)。那里的数字一律是参考，不是标准。

## 边界

- 拿不到对标内容时（无法访问链接、只有图片没有文字）如实说明，不凭想象推测它的文案。
- 不把对标当成必须对齐的标准。对标是参考，不是及格线。
- 不因为对标数据好就照搬。做法能不能成立，取决于你的商品、读者和账号。
