# 封面创作

## 目标

封面要让目标女性用户在小红书双列信息流里第一眼觉得这身搭配好看，并愿意继续看这件配饰的穿搭效果。点击吸引力来自真实成立的穿搭、商品呈现、人物姿态、背景和构图共同形成的视觉重点。

默认制作 3:4 竖版封面，默认不加标题、花字、贴纸或平台元素。需要文字时参见下文「封面文字」一节。

## 推导顺序

### 1. 理解商品

从商品图判断：

- 颜色、图案、材质、软硬程度、边缘和结构；
- 披肩适合的搭法、覆盖范围、垂落方式和合理的自然褶皱；
- 这张图最值得展示的是整身搭配、披肩轮廓、垂落效果、材质细节，还是颜色关系。

不要让模型为了展示商品而拉长、改款、增加部件或使用没有依据的穿戴方式。

### 2. 理解对标图

拆出对标图中真正值得保留的部分：

- 背景地点、空间层次和人物所在位置；
- 光线方向、软硬、明暗与色调怎样形成画面的感受；
- 取景范围、人物大小、构图重心和留白，以及它们怎样组织人物与环境的关系；
- 如需参考姿势，理解身体朝向、手的位置、视线和商品关系为什么能成立。

理解对标图为什么吸引人，不只提取地点和景物。例如，人物面向山谷、周围留有空间，可能是旅行感的重要来源；换成近距离正面人像后，即使景物相同，感受也会改变。结合商品展示需要取舍，不直接照搬人物大小或姿势。

对标图不是整张复制模板。原图的服装、人物、商品、文字和装饰要重新判断，不自动继承。

### 3. 确定点击理由

先回答：目标用户为什么会想点开这张图？例如：

- 想看一身好看的披肩搭配；
- 想看披肩怎样自然垂落或围搭；
- 被颜色、材质或人物与环境的组合吸引；
- 想获得某种通勤、约会、旅行或日常穿搭灵感。

结合用户要求和对标图，确定照片想传达的感受，以及最先吸引视线的内容。这些是后续光影、构图和人物引导的依据，不用抽象情绪词代替画面设计。点击理由必须与后续笔记内容一致，不能用画面无法兑现的夸张承诺。

### 4. 设计完整拍摄方案

按 [共同摄影原则](../SKILL.md#用摄影思维推导画面)，围绕商品、对标图和点击理由协调光影、构图与人物状态，再落实穿搭：

- 人物外貌、发型和妆容，以及由当前注意力和状态推导的表情，不默认微笑；
- 服装的款式、颜色、层次和与披肩的搭配依据；
- 披肩覆盖身体的位置、接触关系、受力和垂落；
- 身体和脸部朝向、视线、手的位置、重心和必要支撑；
- 光源相对人物的方向，脸部与披肩的明暗、背景亮度和人物分离方式；
- 谁持机、机位方向、景别、取景范围，以及人物在画面中的位置、占据多大范围、上下左右留白与环境结构的关系；
- 画面中最先被看见的视觉重点。

服装由 Agent 搭配时要主动变化。白色长裙可以作为一种方案，但不能因为没有指定服装就反复作为默认答案。

### 5. 检查封面是否成立

生成提示词前检查：

- 光影、构图和人物状态是否共同表达了想要的感受，而不只是分别合理？
- 脸部和商品的明暗是否符合人物朝向，人物与环境是否处在同一光线中？
- 姿态、视线和表情能否在照片中体现人物状态，而不依赖画面外的故事解释？
- 人物的位置、大小和留白是否经过选择，还是沿用了居中全身刚好装满的默认安排？它们是否支持当前视觉重点？
- 这身衣服和披肩能在现实中这样穿吗？
- 这个姿势下披肩的接触、受力、褶皱和垂落合理吗？
- 手的位置、身体朝向和机位能同时成立吗？
- 人物与地面、椅子、墙面或其他环境支撑是否相容？
- 缩小到信息流封面后，人物、商品和点击重点是否仍清楚？
- 背景是否保留了对标图的吸引力，同时没有喧宾夺主？
- 头发、披肩边缘、衣摆或环境是否有适合后续轻微动态的自然空间？

发现问题时回到完整拍摄方案调整，不靠叠加大量“不要”来掩盖方案冲突。

## 封面文字

默认不加。穿戴类商品的点击理由来自画面本身——一身搭配好不好看、披肩垂落得自不自然，看照片就能判断，加字反而会削弱画面的完整。

下面几种情况可以加，由用户明确要求，或一起判断后决定：

- 内容的信息密度高，光看画面看不出在讲什么（合集、对比、选购建议、步骤类）。
- 目标读者需要一个人群锚点，才能认出“这是给我的”。
- 换到靠信息或情绪取胜的赛道时（知识、攻略、测评类），文字常常是封面的主要构成。

加的时候守住几条：

- **只放一个重点**。一个人群词加一个痛点或卖点，不堆信息。
- **放在空白处或主体边缘**，不遮商品和人物。
- **主次字号要分得开**，一眼能抓到主要信息。
- 同一个账号固定两三种排布方式，主页看起来是一套，但不要每篇一模一样。
- 文字和标题**错位互补**，不要重复说同一句话。封面给画面或人群，标题补具体利益点。

图片模型渲染中文字符通常不够稳。加了文字的方案，优先让模型**留出干净的排版位置**，文字由用户在上传前自行添加；确实要让模型直接生成文字时，生成后逐字核对，错字、漏字、乱码都不算完成。

## 细节程度

最终提示词描述成片中的一个瞬间，写到“画面可见且会改变成片”的程度。例如，推导时可以用“站在溪边观察对岸”来引导，最终写成：

> 人物位于画面左侧，身体朝向溪流，脸以侧面朝向右侧对岸，目光停留，嘴唇放松。全身入镜但不占满画面，上方保留山谷高度，右侧留出溪流延伸的空间。披肩由肩背承托，两片前侧顺着身体垂下。侧面日光照亮一侧脸颊和披肩褶皱，另一侧保留柔和阴影。

这个示例只说明怎样表达，不作为默认方案。不要只写“姿态优雅、轻轻整理披肩”，也不要写没有依据的精确角度和尺寸。细小的手指弯曲、肩部角度和画面外动作交给模型表现。

## 交付

将完整方案交给 [prompt-and-saving.md](prompt-and-saving.md) 组装为生成用 JSON 提示词。封面确认后，记录它作为后续配图的人物身份依据，不把这一张的表情和构图一并固定。
