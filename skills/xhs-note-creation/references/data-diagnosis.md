# 数据诊断

## 职责与时机

用户给出笔记的数据表现（曝光、阅读、互动），或问"为什么这篇没流量"时使用。这里只做**定位**——判断问题出在哪一环，不直接改写内容；定位之后回到对应的 reference 处理。

用户不给数据时不主动索取，也不联网查询经营数据。

## 前提

下面所有数字都是**参考区间，不是平台标准**。

- 平台没有公布过统一的合格线，任何精确阈值都是运营者的经验归纳。
- 不同赛道的均值差别很大。穿搭类竞争激烈、均值高，冷门类目均值低，拿同一个数字去比没有意义。
- 唯一可靠的做法是**和后台自带的同行对比比**，以及和自己历史内容比。

所以这些区间只用来猜"问题可能在哪"，不用来判定一篇笔记好不好。

## 指标怎么算

| 指标 | 口径 | 说明 |
|---|---|---|
| 曝光量 | 平台把笔记推出去的次数 | 创作者控制不了 |
| 阅读量（小眼睛） | 实际点开的人数 | 封面和标题的结果 |
| 点击率 | 阅读量 ÷ 曝光量 | 封面标题的体检指标 |
| 互动率 | （点赞 + 收藏 + 评论 + 分享）÷ 阅读量 | 正文的体检指标 |
| 收藏率 | 收藏 ÷ 阅读量 | 内容"有用"的程度 |
| 涨粉 | 新增关注 | 内容"值得跟着看"的程度 |

## 参考区间

**点击率**

| 区间 | 可能的含义 |
|---|---|
| 低于 5% | 偏低。封面或标题没让人想点，先查这两个 |
| 5% ～ 10% | 良好 |
| 高于 10% | 优秀，封面标题这一环基本没问题 |

**互动率**

| 区间 | 可能的含义 |
|---|---|
| 低于 3% | 偏低。读者点进来了，但没有能带走的东西 |
| 3% ～ 5% | 一般 |
| 高于 10% | 有进一步扩散的潜力 |

**互动结构**

| 现象 | 说明内容偏向 |
|---|---|
| 收藏远高于评论 | 有用，但没留讨论空间，属于工具型 |
| 评论远高于收藏 | 引发共鸣或讨论，属于情绪型 |
| 点赞高，收藏和评论都低 | 看着舒服，但没留下印象 |
| 什么都低 | 回到最前面查，通常是没接住读者的具体问题 |

互动之间的轻重顺序，业内通行的经验是「关注 > 转发 > 评论 > 收藏 ≈ 点赞」，也就是门槛越高的行为越被看重。精确权重没有官方公布，记住这个方向就够，不用当公式算。

## 按环节定位

拿到数据先按顺序往下走，哪一层断层就在那一层处理：

```
曝光低              → 方向或账号标签的问题，看 [选题生成](topic-discovery.md)
曝光正常但点击低    → 封面和标题的问题，看 [封面创作](cover-creation.md) 与 [标题创作](title-writing.md)
点击正常但互动低    → 正文的问题，看 [正文创作](body-writing.md)
互动正常但没成交    → 商品本身或展示方式的问题，不在本 Skill 的处理范围
```

阅读量长时间停在个位数或几十，最常见的原因是封面没让人点，不是"被限流"。没有收到违规提示时，优先按封面标题排查，不要归因到账号权重这类说不清的地方。

## 处置纪律

- **改，不要删**。数据不好的笔记优先改封面和标题后继续看。删除会让主页变空，对下一条笔记没有帮助；隐藏的效果约等于删除。
- **发布后编辑会重新走一遍审核**，也可能重新进入推荐。改动有代价，所以把关要放在发布前。
- **挂了商品链接之后通常不能再编辑**，改动要在发布前做完。
- 同一篇不要反复改很多次。改两三次仍没起色，说明是方向问题，回到选题层重新考虑。

## 边界

- 没有数据时凭封面标题直接判断，并说明这是观察，不是结论。
- 给的是"可能的原因和下一步"，不下"这篇一定不行"的判断。
- 不承诺改动之后的效果，也不预测能否进入某个流量层级。
