# 后续配图

## 目标

在已确认的封面基础上，继续展示同一件商品。人物必须保持一致；每张图都应带来新的展示价值，同时与封面的穿搭审美和整篇笔记保持协调。

## 默认继承与变化

- 人物身份和可辨认的脸型、五官特征、发型以封面为依据；表情、视线、头部朝向及相应的透视、光线和表情带来的脸部变化按本张状态重新设计，不要求复制封面的脸部截图。
- 商品外观、结构、颜色和材质继续以商品图为依据。
- 没有新背景参考时，默认沿用封面的环境；同一地点不锁定人物站位、摄影者位置或取景，人物在画面中的位置、大小和留白仍需按本张目的设计。
- 用户提供新背景参考时，使用新背景，并重新推导与新环境相容的动作、光线和构图。
- 服装默认延续封面；用户明确要求或展示目标需要时可以更换，但更换后仍要与人物、披肩和场景协调。

## 推导顺序

### 1. 确定本张要补充什么

结合用户要求、封面和已有配图，明确本张的展示目的，例如：

- 展示另一种整体搭配角度；
- 展示披肩的另一种合理围搭或垂落；
- 展示材质、边缘、花纹或局部细节；
- 展示人物与商品在同一环境中的另一种关系；
- 为后续轻微动态提供不同的头发、衣摆、披肩或环境变化。

不要为了“换一张”而随机换脸、换服装或换背景。

### 2. 选择背景与延续范围

没有新参考时，先在封面环境中选择合理的位置和视角，例如门口、窗边、座位旁或同一街区的另一段空间。不要擅自把同一篇笔记换成完全无关的地点。

有新背景参考时，先理解其环境和构图，再判断封面人物、服装和披肩如何进入新场景。新背景只提供它承担的内容，不自动带入原人物、原服装或原图中的其他商品。

### 3. 先考虑画面安排，再协调人物状态与光影

按 [共同摄影原则](../SKILL.md#用摄影思维推导画面)，从本张展示目的出发，先考虑人物在画面中的位置、占据多大范围、上下左右的空间与背景结构，再选择机位和取景。不要先固定封面的画面安排，再只问“这次换什么动作”；即使人物身份、衣服和地点延续，也不把封面当作构图模板。

随后结合人物此刻的注意力与状态，设计表情、视线、身体和脸部朝向、手的位置、重心、支撑及披肩状态，并按朝向与机位重新协调脸部、商品和环境的光影。推导时可以来回调整这些选择，不机械地按步骤各选一个答案。选定一个现实中能够完成、拍出来协调的瞬间，最终提示词写可见状态，不用画面外故事代替姿态和表情；不默认复制封面的微笑，也不强制每张换一种表情。

手接触披肩时写清接触位置和披肩最终状态；不接触时也要写清披肩相对身体的位置、受力和垂落。不要只写“换个姿势”“自然展示”。

### 4. 检查与已有图片的差异

比较实际可见的：

- 人物在画面中的位置、大小，以及上下左右的留白；
- 表情、视线和脸部朝向，在当前取景中是否有可见的状态变化；
- 身体朝向和手臂关系；
- 人物与披肩的接触、覆盖和垂落；
- 人物与背景的关系；
- 机位、景别和视觉重点。

生成前将本张方案与封面和已有配图比较。如果只换手势或动作，人物位置、大小和周围空间基本不变，重新考虑画面安排，而不是继续增加动作。只换衣服、脸型或背景也不能自动算作充分变化，不用换身份或夸张表情制造差异。变化应服务本张目的，不要求所有项目每张都改变；用户明确要同机位连续画面时，保留其要求。

## 交付

将本张方案和封面人物参考交给 [prompt-and-saving.md](prompt-and-saving.md) 组装。按配图顺序保存为 `1`、`2`、`3` 等；封面仍是人物身份一致性的主要依据，不负责固定本张表情和构图。
