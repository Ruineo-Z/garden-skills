# 笔记方向讨论

## 输入与时机

默认配图先行。用户准备写文案时，读取商品图、已认可的封面和配图、当前请求，以及用户提供且确实要参考的文字。以实际看过的素材为依据，不把图片提示词当作成图，不默认联网搜对标；用户给出链接时，实际读取后再分析，无法访问则说明。

商品图用于辨认外观，配图用于理解搭配与场景；商品事实的边界见 [总入口](../SKILL.md#商品信息与参考边界)。已确认主方向时直接沿用，除非用户要求换方向或素材变化使它无法成立。

## 推导三个方向

先判断：配图的吸引力是什么，商品在其中起什么作用，哪些读者可能喜欢，怎样把这种兴趣转成“买回来我能怎么用”。购买理由可以是配色、搭配效果或对某种风格的向往，不必强造痛点。

提出三个在内容重点或购买理由上有实质区别的方向，不是同一标题换词。根据当前素材选择，例如搭配方法、场景穿搭、单品设计；这些不是每次必用的分类。只展示一套搭配时，不提无素材支持的“三种搭法”“不同身材测评”。

每个方向简短说明：

- **准备讲什么**：主要内容和有依据的图片或商品特点。
- **点击理由**：读者为什么想看，封面怎样支持它。
- **主题关键词**：与内容相符的商品、搭配、风格或场景词；没查搜索数据时不称为热搜词。
- **购买理由**：正文怎样解释效果或用法，让读者判断是否适合自己。

Agent 推荐其中一个，并简述依据；这是创作判断，不是流量预测。素材有限时坦诚说明方向之间的区别较小，不编造卖点来凑数。

## 与用户确定方向

展示提案后等待讨论，不提前写完整文案或重做图片。用户可以选择、调整或结合部分内容；Agent 将反馈归成一个清晰主方向，保留必要辅助内容，不把所有方向堆进一篇。

用户已选定方向或明确让 Agent 自行决定时继续创作，不重复请求确认。用户直接提供明确标题或文案意图时，视为已有方向；缺少关键事实才追问。

## 对标的使用

分析文字对标的点击理由、主题、开头、展开方式、语气和结尾，再判断是否适合商品和配图。没有文案对标时自行推导，不要求补一篇参考。美景笔记可以贡献表达灵感，但风景故事不能无理由变成商品笔记的主内容。

借鉴依据：ShopAgent 的 NOTE-002、NOTE-003 强调目的、人群、场景和内容承接；[Vic 的种草经验](https://www.digitaling.com/articles/1012787.html)强调场景与商品特点的组合需要验证。这里保留推导方法，不把投放策略直接用于自然流量，也不依赖另一个项目的文件执行。
