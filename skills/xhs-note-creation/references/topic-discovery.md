# 选题生成

## 职责与时机

当用户不知道这一篇写什么、需要一批候选方向，或想把一个模糊想法变成能写的选题时使用。这里产出的是**内容方向**，不是标题或正文；方向确定后交给 [创作准备与笔记方向](note-direction.md) 锁定时效与人群，再进入图片和文案。

用户已有明确想法时直接沿用，不走这套流程。

## 先回答三个问题

一个方向成立，需要同时答出下面三件事。答不出就先补，不要动笔。

| 问题 | 要答到什么程度 |
|---|---|
| 写给谁 | 具体到一个能对上号的人群，不是"女生"这类全覆盖说法 |
| 她遇到什么 | 能用读者自己的话复述出来，例如"披肩一裹就像披了床单" |
| 她能带走什么 | 看完之后她拿到了什么，而不是店家想卖什么 |

第三条最容易自欺。把"我这件披肩工艺好"改写成"她看完知道怎么把披肩裹出腰线"，才算成立。

## 把自嗨改成读者视角

下笔前用三条校准：

- **读者视角**：把"我有什么"换成"她能拿到什么"。
- **可感知价值**：卖点要能被感知。工艺、成分、工序本身不是价值，它们带来的结果才是。
- **叠加场景**：同一个人群在不同场景里需求不同，拆开就是不同的方向。

## 九宫格裂变

想不到方向时用这个办法。机械，但有效，而且不需要任何后台数据。

```
画三个 3×3 的格子，中心格分别写 人群 / 场景 / 痛点，周围八格填满
→ 三类各取一格组合，就是一个候选方向
```

以披肩为例：

| 中心 | 周围八格可以填 |
|---|---|
| 人群 | 学生党、通勤族、微胖、小个子、宝妈、中长发、旅行爱好者、怕冷星人 |
| 场景 | 通勤地铁、周末逛街、草原旅拍、办公室空调、秋夜散步、朋友生日、参加婚礼、周末宅家 |
| 痛点 | 不会配色、披上显壮、不知道怎么固定、懒得搭配、照镜子比例奇怪、脖子显短、不知道送人送什么、一裹就像床单 |

组合示例：

- 通勤族 × 办公室空调 × 懒得搭配 → 一件放在工位随时能披的外搭
- 小个子 × 草原旅拍 × 照镜子比例奇怪 → 小个子旅拍怎么让披肩不压身高
- 宝妈 × 朋友生日 × 不知道送什么 → 送朋友一件不容易挑错的披肩

一个格子填满就能裂变出几十个方向。想到新的人群或场景时回来补格子。

## 五个方向模板

九宫格给出的是"谁在什么场景遇到什么"，下面五个模板把它翻成一个更具体的内容角度。

| 模板 | 读者为什么看 | 披肩类写法示例 |
|---|---|---|
| 实用 | 想解决一个具体问题 | 披肩的三种固定方式，风大也不散 |
| 共鸣 | 觉得"这说的就是我" | 一裹就显壮，可能是一直搭错了 |
| 认知 | 想知道点行内的东西 | 挑披肩先看这三个地方，不用听卖家说 |
| 反常识 | 与预期不一样，想看看 | 披肩不一定配长裙，配这个反而更好 |
| 热点与节令 | 正在关心这件事 | 降温了，通勤路上怎么一层就够 |

**热点与节令要加一道约束**：用之前先确认这个话题的人群和读者是同一批人。借了关注度但来的人不关心配饰，就只是虚假热闹。没有共同人群时宁可不用，也不要为了时效硬加主题。

## 使用者与买单的人

有些商品是买给自己用，有些是买来送人。这两种情况的读者不是同一批人，内容要对着**实际掏钱的那个人**写。

披肩的礼物属性强，两个方向都成立，但要在开始时选定一个：

- **送给别人** → 读者是挑礼物的人，内容围绕送谁、什么场合送、怎么显得有心思。
- **买给自己** → 读者是自己穿的人，内容围绕我穿好不好看、怎么搭、什么时候穿。

选定之后再往下推导。不要在正文里两边都顾，那样两边都不像。

## 选题来源

方向不够时按当前能做到的往下取：

- **搜索框联想**：用"人群 + 场景"而不是品类词去搜，看下拉提示里读者自己怎么描述需求。
- **评论区与私信**：用户反复问的问题，本身就是一整个方向。
- **同行的对标内容**：看哪些方向在同类账号上被反复做（怎么找、怎么拆见 [对标分析](benchmark-analysis.md)）。
- **季节与节日**：只在和商品确实相关时用。具体天气和活动信息没有依据就不写成已核实事实。
- **自己发过的内容**：表现好的方向可以换个角度再做一次，不是重复发同一篇。

## 输出

给 3～5 个候选方向，每个写清：写给谁、什么场景、她能得到什么、商品和画面准备怎么支持。说明依据来自哪里（用户提供的信息、可见的评论问题，还是我们的推测）。

推测的方向要标明是推测，不冒充已验证的用户需求。用户选定后再进入下一环节，不提前展开标题和正文。

## 边界

- 不编造读者的痛点。拿不出依据的需求作为建议提出，由用户判断是否真实存在。
- 不承诺流量、排名或成交。方向好只说明值得写，不等于会火。
- 不为让方向好听而夸大商品能力。商品能支持什么，以商品图和用户提供的资料为准。
