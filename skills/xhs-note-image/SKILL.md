# 小红书笔记配图创作

这是一份面向本地 Agent 的创作 skill。它负责理解商品和参考图、推导成立的穿搭拍摄方案、组织最终提示词，并规定结果保存方式。实际生图或改图由当前 Agent 使用已有的图片工具完成。

## 先判断当前任务

根据当前请求和上下文，只读取需要的参考文件：

- **封面创作**：没有已确认封面，用户要开始一篇笔记、制作首图或明确要求封面时，读取 [cover-creation.md](references/cover-creation.md)。
- **后续配图**：上下文已有用户认可的封面，用户要继续制作第 1 张、第 2 张等配图时，读取 [follow-up-images.md](references/follow-up-images.md)。
- **图片修改**：用户针对已有图片提出修改、重做或调整时，读取 [image-revision.md](references/image-revision.md)。
- **提示词与保存**：每次需要生成或修改提示词时读取 [prompt-and-saving.md](references/prompt-and-saving.md)。

“再来一张”不能单独决定任务类型。结合上下文判断它是在重做封面、追加配图，还是修改当前图片；只有上下文不足且会影响参考图或人物一致性时才提问。

## 共同原则

- 商品图决定商品的颜色、图案、材质、裁剪、部件、连接关系和可行穿戴方式。文字不要臆造参考图看不清的商品细节。
- 对标图默认提供背景参考：理解环境、空间关系、光线、色调和构图，再结合当前商品重新设计。对标图有好看的姿势时可以参考，但不直接照搬原人物、服装、商品、文字、贴纸或平台界面。
- 人物、服装、商品状态、动作、环境和机位必须组成现实中能够完成的穿搭拍摄。不要只写“自然”“优雅”“好看”，也不要把互不相容的动作、衣服和商品状态拼在一起。
- 默认画面质感是穿搭博主用手机拍出的照片：穿搭、妆发和姿势经过设计，画面清晰、协调、上镜；保留真实皮肤、材质和现场感，允许适度调色和修饰，不做过度磨皮或商业影棚效果。
- 先在内部形成完整、成立的拍摄方案，再写提示词。最终提示词具体到画面可见、会影响成片的关系，例如身体朝向、视线、手相对身体的位置、手与披肩的接触、披肩的垂落和必要的支撑关系。
- 不写没有依据的角度、厘米数或每个关节的精确数值。半身或局部取景不为画面外的腿脚安排细节。
- 生成前检查方案。生成后直接交付，由用户判断；不自动看图审核、不因视觉质量自动重试。收到反馈后按图片修改规则处理。
- 本 skill 不编写生图脚本、不规定 API 请求，也不替代本地 Agent 已有的图片工具。最终提示词和参考图职责交给当前 Agent 执行。

## 必要信息

- 缺少商品图时，先索取商品图。
- 做封面但没有对标图时，如果上下文已有背景或风格方向就直接沿用；如果没有，先询问一个具体方向，例如街拍、咖啡店、室内窗边或其他场景。用户也可以授权 Agent 自行决定。
- 做后续配图但没有可用的已确认封面时，需要先取得封面或明确的人物依据。
- 修改图片但没有目标原图时，先索取目标图片。

## 参考图职责

每张参考图都要在方案和最终提示词中明确用途：

- 封面通常使用商品图和对标图；用户提供模特图时才加入模特参考。
- 后续配图通常使用商品图和已确认封面；用户提供新的背景或姿势参考时按需加入。
- 修改图片必须使用目标原图；商品图、封面或其他参考图只在确实影响修改时加入。

不要只在文字里提到参考图却不把它交给图片工具；实际能否传入多张图由当前 Agent 的工具能力决定。

## 共同交付规则

- 用户只要提示词时，交付完整提示词，不调用图片工具。
- 用户要求直接出图时，先完成方案和提示词，再由本地 Agent 调用已有工具。
- 用户要求先看方案或确认后生成时，先停在方案和提示词，不提前出图；确认后沿用已确认内容，只修改用户反馈的部分。
- 生成或修改失败时如实说明原因，保留完整提示词，不假称已生成，不创建虚假的图片路径。
