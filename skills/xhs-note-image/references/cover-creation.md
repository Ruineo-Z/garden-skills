# 封面创作

## 目标

封面要让目标女性用户在小红书双列信息流里第一眼觉得这身搭配好看，并愿意继续看这件配饰的穿搭效果。点击吸引力来自真实成立的穿搭、商品呈现、人物姿态、背景和构图共同形成的视觉重点。

默认制作 3:4 竖版封面，默认不加标题、花字、贴纸或平台元素。用户明确要求文字时，再把文字作为独立的排版要求加入提示词。

## 推导顺序

### 1. 理解商品

从商品图判断：

- 颜色、图案、材质、软硬程度、边缘和结构；
- 披肩适合的搭法、覆盖范围、垂落方式和合理的自然褶皱；
- 这张图最值得展示的是整身搭配、披肩轮廓、垂落效果、材质细节，还是颜色关系。

不要让模型为了展示商品而拉长、改款、增加部件或使用没有依据的穿戴方式。

### 2. 理解对标图

拆出对标图中真正值得保留的部分：

- 背景地点、空间层次和人物所在位置；
- 光线方向、色调和整体氛围；
- 取景范围、构图重心和留白位置；
- 如需参考姿势，理解身体朝向、手的位置、视线和商品关系为什么能成立。

对标图不是整张复制模板。原图的服装、人物、商品、文字和装饰要重新判断，不自动继承。

### 3. 确定点击理由

先回答：目标用户为什么会想点开这张图？例如：

- 想看一身好看的披肩搭配；
- 想看披肩怎样自然垂落或围搭；
- 被颜色、材质或人物与环境的组合吸引；
- 想获得某种通勤、约会、旅行或日常穿搭灵感。

点击理由必须与后续笔记内容一致，不能用画面无法兑现的夸张承诺。

### 4. 设计完整拍摄方案

围绕商品、对标背景和点击理由，一起设计：

- 人物外貌、发型、妆容和表情；
- 服装的款式、颜色、层次和与披肩的搭配依据；
- 披肩覆盖身体的位置、接触关系、受力和垂落；
- 身体和脸部朝向、视线、手的位置、重心和必要支撑；
- 谁持机、机位方向、景别、人物位置和取景范围；
- 画面中最先被看见的视觉重点。

服装由 Agent 搭配时要主动变化。白色长裙可以作为一种方案，但不能因为没有指定服装就反复作为默认答案。

### 5. 检查封面是否成立

生成提示词前检查：

- 这身衣服和披肩能在现实中这样穿吗？
- 这个姿势下披肩的接触、受力、褶皱和垂落合理吗？
- 手的位置、身体朝向和机位能同时成立吗？
- 人物与地面、椅子、墙面或其他环境支撑是否相容？
- 缩小到信息流封面后，人物、商品和点击重点是否仍清楚？
- 背景是否保留了对标图的吸引力，同时没有喧宾夺主？
- 头发、披肩边缘、衣摆或环境是否有适合后续轻微动态的自然空间？

发现问题时回到完整拍摄方案调整，不靠叠加大量“不要”来掩盖方案冲突。

## 细节程度

最终提示词写到“画面可见且会改变成片”的程度。例如：

> 身体略侧向镜头，脸转向镜头；靠近镜头一侧的手在胸前握住披肩前缘，手肘靠近身体，另一只手自然垂落；披肩覆盖双肩，两端沿身体前侧垂下。

不要只写“姿态优雅、轻轻整理披肩”，也不要写没有依据的精确角度和尺寸。细小的手指弯曲、肩部角度和画面外动作交给模型表现。

## 交付

将完整方案交给 [prompt-and-saving.md](prompt-and-saving.md) 组装为生成用 JSON 提示词。封面确认后，记录它作为后续配图的人物依据。
