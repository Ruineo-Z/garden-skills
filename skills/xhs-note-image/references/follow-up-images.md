# 后续配图

## 目标

在已确认的封面基础上，继续展示同一件商品。人物必须保持一致；每张图都应带来新的展示价值，同时与封面的穿搭审美和整篇笔记保持协调。

## 默认继承与变化

- 人物外貌、脸型、发型和整体身份以封面为依据，必须保持一致。
- 商品外观、结构、颜色和材质继续以商品图为依据。
- 没有新背景参考时，默认沿用封面的环境，在同一地点中改变位置、角度、景别或取景。
- 用户提供新背景参考时，使用新背景，并重新推导与新环境相容的动作、光线和构图。
- 服装默认延续封面；用户明确要求或展示目标需要时可以更换，但更换后仍要与人物、披肩和场景协调。

## 推导顺序

### 1. 确定本张要补充什么

结合用户要求、封面和已有配图，明确本张的展示目的，例如：

- 展示另一种整体搭配角度；
- 展示披肩的另一种合理围搭或垂落；
- 展示材质、边缘、花纹或局部细节；
- 展示人物与商品在同一环境中的另一种关系；
- 为后续轻微动态提供不同的头发、衣摆、披肩或环境变化。

不要为了“换一张”而随机换脸、换服装或换背景。

### 2. 选择背景与延续范围

没有新参考时，先在封面环境中选择合理的位置和视角，例如门口、窗边、座位旁或同一街区的另一段空间。不要擅自把同一篇笔记换成完全无关的地点。

有新背景参考时，先理解其环境和构图，再判断封面人物、服装和披肩如何进入新场景。新背景只提供它承担的内容，不自动带入原人物、原服装或原图中的其他商品。

### 3. 推导完整姿势

重新共同设计身体朝向、脸部朝向、视线、手的位置、重心、支撑关系、披肩状态和机位。动作可以有穿搭博主的设计感，但必须是现实中能够完成、拍出来协调的姿势。

手接触披肩时写清接触位置和披肩最终状态；不接触时也要写清披肩相对身体的位置、受力和垂落。不要只写“换个姿势”“自然展示”。

### 4. 检查与已有图片的差异

比较实际可见的：

- 身体朝向和手臂关系；
- 人物与披肩的接触、覆盖和垂落；
- 人物与背景的关系；
- 机位、景别和视觉重点。

只换衣服、脸型、背景，或把站姿换成坐姿，不能自动算作充分变化。如果动作和商品关系仍相似，重新设计完整方案；不要使用少见、夸张或不合理的动作强行制造差异。
